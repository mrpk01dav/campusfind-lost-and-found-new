# Demo script

Use fictional details only. Browse the sample records, search by location/category, open a listing, and inspect the explainable match reasons. Submit one lost report and one corresponding found report with matching category/color/location/date; open the details to see a potential match. Submit a fictional claim and change its demo status in My claims. Mark a locally created report recovered.

Demo data seeds only on a fresh browser origin. It will not automatically replace saved local data. To reset, clear site data for the local origin using the browser's site settings.
